# Jomlat Al Khateeb Groceries

أريد بناء موقع إلكتروني احترافي ومتجاوب بالكامل لـ "متجر مواد غذائية وبقالة" باسم (جملة الخطيب).

المواصفات والصفحات المطلوبة في الكود:

1. التصميم والهوية:

- أريد تصميماً حديثاً ومريحاً للعين، يناسب متاجر الأغذية (استخدم ألواناً مثل الأخضر، الأبيض، أو البرتقالي الهادئ).

- الموقع يجب أن يكون باللغة العربية (يدعم الـ RTL) ومتوافقاً مع الشاشات والموبايل.

2. الصفحات الأقسام المطلوبة:

- الصفحة الرئيسية (Home Page): تحتوي على شريط علوي (Navbar) فيه شعار المتجر، شريط بحث عن المنتجات، وسلة المشتريات. وبها قسم ترحيبي (Hero Section) يعرض لافتة (Banner) للعروض، يليه قسم لـ "أحدث المنتجات" وقسم لـ "الأكثر مبيعاً".

- صفحة المنتجات (Products/Shop Page): تعرض المنتجات على شكل بطاقات (Cards)، تحتوي كل بطاقة على: صورة المنتج، اسمه، السعر، وزر "أضف إلى السلة". مع وجود تصفية (Filters) حسب الفئات (مثل: ألبان وأجبان، معلبات، زيوت، حلويات، إلخ).

- سلة المشتريات (Cart) والـ Checkout: تتيح للمستخدم رؤية المنتجات التي أضافها، تعديل الكميات، وحساب المجموع الكلي، مع نموذج بسيط لإدخال الاسم، رقم الهاتف، والعنوان لإتمام الطلب.

- صفحة التواصل (Contact Us): تحتوي على معلومات الاتصال بالمتجر (رقم الهاتف، العنوان، ورابط الواتساب).

3. الميزات التفاعلية (Interactive Features):

- تفعيل خاصية إضافة وحذف المنتجات من السلة وتحديث السعر الإجمالي تلقائياً (State Management).

- شريط بحث ذكي لتصفية المنتجات المعروضة حسب الاسم فوراً أثناء الكتابة.

- إضافة زر سريع "اطلب عبر الواتساب" في نهاية عملية الشراء ليرسل تفاصيل الطلب مباشرة إلى رقم المتجر.

يرجى كتابة الأكواد كاملة وبنية ملفات منظمة وسهلة التعديل.
